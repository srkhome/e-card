1. 【使用者】如何製作與發送數位名片

任何一般的 LINE 使用者，只要點開這個網站即可直接開始使用：

步驟一：選擇範本或填寫資料

開啟網站後，點擊右上角 「名片範例」 或 「商品範例」 快速帶入基礎版型。

在左側欄位輸入您的照片網址、姓名/職稱、自我介紹與個人網站/社群按鈕連結。

點擊 「+ 新增卡片」 可建立多頁輪播名片（例如：第一頁個人名片、第二頁服務項目、第三頁聯絡方式），最多支援 10 張卡片。

步驟二：即時預覽效果

右側的手機模擬器會實時呈現卡片在 LINE 聊天室呈現的模樣，確認文字不超出邊框與照片顯示正常。

步驟三：一鍵傳送給 LINE 好友 / 群組

點擊下方綠色按鈕 「傳送至 LINE 好友 / 群組」。

系統會自動喚起 LINE 的「選擇傳送對象」視窗。

勾選要傳送的好友或群組，點擊傳送即可！

2. 【使用者】常見問題（FAQ）

Q1：使用這個工具發送名片需要付費嗎？

完全免費！ 訊息是由您個人的 LINE 帳號發送給朋友，就像您平常在 LINE 發文字或照片一樣，不產生任何費用。

Q2：收到名片的人需要下載 App 或安裝東西嗎？

不需要！ 接收者會在聊天室直接看到精美的卡片，點擊按鈕即可打開您設定的網頁或連結。

Q3：為什麼圖片會無法顯示？

請確保您的圖片連結是以 https:// 開頭（例如 Imgur、Unsplash 或您個人網站上的圖片網址）。

3. 【開發者】系統架構與免費原理

如果您是這個網站的開發者或站長，本系統的運作架構如下：

┌────────────────────────┐       ┌────────────────────────┐       ┌────────────────────────┐
│  一般使用者 (User)     │       │  您架設的網站 (LIFF)   │       │  LINE App (個人帳號)   │
│  開啟網頁輸入名片內容   │ ────> │  自動包裝成 Flex JSON  │ ────> │  喚起 Share Picker    │
└────────────────────────┘       └────────────────────────┘       │  發送給好友/群組       │
                                                                  └────────────────────────┘


為什麼免費？ 訊息傳送呼叫的是 LINE SDK 的 liff.shareTargetPicker()，這屬於 C2C（用戶對用戶）或 C2G（用戶對群組）的分享行為，不經過 LINE 官方帳號 API，因此完全不扣扣繳額度。

站長角色：您只需申請 一組全域 LIFF ID 並填入網站原始碼中，所有造訪您網站的訪客就能共享此發送功能！

4. 【開發者】如何申請與設定全域 LIFF ID

請跟隨以下步驟申請您專屬的全域 LIFF ID：

第一步：登入 LINE Developers Console

前往 LINE Developers 主控台。

使用您一般的 LINE 帳號 登入。

第二步：建立 Provider & LINE Login Channel

點擊 「Create a new provider」，輸入提供者名稱（如：Digital Card Hub）。

在 Provider 內點擊 「Create a LINE Login channel」：

Company or owner's country/region：選擇 Taiwan。

Channel name：例如 免費數位名片分享器。

App types：勾選 Web app。

點擊 Create 建立。

第三步：新增 LIFF App 並啟用 Share Target Picker

切換至 「LIFF」 頁籤，點擊 「Add」。

填寫設定：

LIFF app name：數位名片發送器。

Size：選擇 Full。

Endpoint URL：填入您部署好的網站 URL（必須是 https://）。

Scopes：勾選 profile 與 openid。

【關鍵點】開啓權限：

找到 「Share Target Picker」，切換為 On（一定要開，否則無法發送）。

點擊 Add。

第四步：取得 LIFF ID 並發布

複製產生的 LIFF ID（格式如：2001234567-AbCdEfGh）。

將此 LIFF ID 設定到網頁程式碼 index.html 的 DEFAULT_LIFF_ID 變數中。

將 Channel 狀態從 Developing 切換為 Published，即可開放給全網一般使用者免費使用！
